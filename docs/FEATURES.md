# Feature tracking

This file no longer duplicates the implementation checklist. Its original
Intro-only checklist marked shipped features as unfinished and did not reflect
the current shared Intro, General, and ICPC workflow.

The current product behavior is documented in [Project scope](PROJECT_SCOPE.md)
and the detailed interface direction is in [Design](../design.md). GitHub Issues
are the source for planned and active work: [CappyCode Issues](https://github.com/ehuerta6/cappy-code/issues).

Only describe a feature as implemented after verifying it in the current code,
tests, and accepted project decisions. Keep completed behavior in the product
documentation and future work in its Issue until it ships.
